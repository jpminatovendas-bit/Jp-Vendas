JP Minato · MVP 1.23.1

“Rota não encontrada” indica que o servidor em execução não oferece a API do prompt. Não significa falta de um primeiro prompt salvo. Este pacote atualiza interface e servidor juntos. Não use somente a pasta web desta vez.

Aplicar na instalação atual

  1. Conclua ou cancele trabalhos do programa. Copie para um bloco de notas qualquer prompt digitado ainda não salvo e feche as abas do JP Minato.
  2. Extraia o ZIP em uma pasta temporária. Não abra o programa dessa cópia.
  3. Copie todo o conteúdo de mvp-jp-minato para a instalação atual, mesclando pastas e substituindo arquivos do aplicativo. Pelo registro enviado, a pasta ativa é E:\Documentos_Usuário\Área de Trabalho\Programa JP, onde estão app.py, ABRIR-JP-MINATO e dados. Confirme que app.py, launcher.py, extractor_prompt.py e web/index.html estão nessa mesma instalação. Não apague nem substitua dados.
  4. Abra PARAR-JP-MINATO da instalação atualizada e aguarde a confirmação. O iniciador novo usa comunicação local sem proxy. Se informar que não conseguiu encerrar, salve seus outros trabalhos e reinicie o Windows após a cópia do pacote. Isso encerra o processo Python antigo; não é necessário apagar registros ou banco.
  5. Com servidor parado, mantenha uma cópia de segurança de dados inteira. Se o programa iniciar automaticamente com o Windows, pode abrir ABRIR-JP-MINATO atualizado e usar Parar servidor para atualizar para fazer esse backup.
  6. Abra ABRIR-JP-MINATO da instalação atual. No escritório, também pode acessar http://127.0.0.1:8765. Pressione Ctrl+F5. Confira MVP 1.23.1.
  7. Abra a conferência do servidor local. Deve informar version 1.23.1 e capabilities contendo extractor_prompt_v1. Esse endereço confirma o servidor em execução; o cabeçalho da página sozinho não confirma a versão Python.
  8. Abra Extrator de contatos → Prompt da IA. Sem personalizado salvo, carrega Padrão 1.23 · revisão 0 (a estratégia padrão é a da 1.23). Cole seu texto, clique Salvar prompt e confira Personalizado/revisão. Execute uma nova extração com OpenAI/API ativa e confira prompt custom e a revisão no diagnóstico.

O que mudou

Leitura do prompt independente de outras operações, erro persistente no painel, limite de resposta de 20 segundos, leitura única e salvamento esperando a revisão inicial. Preserva texto digitado durante leitura ou gravação. Erro 404 explica que é necessário atualizar/reiniciar o servidor. Histórico, revisão e proteção contra outra janela mantidos.

O iniciador confere a versão real e a presença da API do prompt. Não reutiliza silenciosamente servidor de outra versão nem anuncia encerramento se há servidor ativo sem correspondência ao registro desta pasta. Não encerra processos de outras aplicações.

Extensão continua 1.16.1, sem alteração. Não é necessário reconfigurar chave, VPN, acervo ou banco. Não remova empresa.sqlite, seus arquivos auxiliares ou a pasta dados.

Verificação

265 testes Python, teste Node da interface e Chromium com Python/Node/SQLite temporários aprovados. Início real do app.py em cópia limpa confirmou GET/POST do prompt, padrão, gravação e encerramento local. API OpenAI simulada, sem chamada paga, conta real ou banco de produção. Instalação/VBS, proxy e VPN físicos do Windows não foram executados nesta sessão.
