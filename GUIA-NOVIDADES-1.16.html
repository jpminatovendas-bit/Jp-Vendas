JP Minato 1.16

Atualize o aplicativo e recarregue a extensão 1.16.0 antes de usar as novas funções. Preserve a pasta dados e faça backup completo com o servidor parado.

1. Agenda Google Contatos

O CSV funciona sem configurar uma conta. Para atualizar os mesmos contatos sem duplicar, configure a conexão por API uma vez no escritório:

  1. Acesse Google Cloud Console com a conta responsável. Crie ou selecione um projeto e habilite Google People API.
  2. Em Google Auth Platform / tela de consentimento, configure o aplicativo. Para uso em teste, inclua sua própria conta nos usuários de teste. Solicite o escopo de contatos https://www.googleapis.com/auth/contacts, além de openid/email para identificar a conta. As regras de teste e autorização podem exigir nova conexão mais tarde.
  3. Crie cliente OAuth do tipo Aplicativo para computador e baixe o JSON. Não use chave de API ou cliente Web. Não envie o JSON nem tokens no chat.
  4. No computador do escritório, abra o MVP pelo endereço local http://127.0.0.1:8765 → Agenda Google → Conectar conta. Selecione o JSON e clique Autorizar conta no computador do escritório. Escolha a conta e autorize no navegador do escritório. O retorno OAuth é local: esta etapa não deve ser iniciada no computador de casa.
  5. Confira o e-mail conectado. Selecione explicitamente selecionados, filtros atuais ou município aberto. Clique Conferir criação / atualização no Google.
  6. Confira quantidades e conflitos. Se o telefone/e-mail já existir, escolha o contato correto para vincular; só escolha Criar separado quando forem realmente contatos distintos. Em conflito de edição manual, revise os dois cadastros e faça nova prévia. Clique Salvar contatos revisados no Google.
Depois da autorização inicial no escritório, a prévia e a sincronização podem ser usadas pelo navegador de casa via VPN. A gravação é iniciada por você, não acontece instantaneamente a cada edição. Nenhum contato é excluído automaticamente.

As credenciais ficam no servidor, protegidas pelo usuário Windows com DPAPI. Em outro computador/usuário, autorize novamente. Em ambientes de desenvolvimento não Windows, o arquivo fica com permissão restrita 0600; não é uma instalação de produção validada.

Os nomes são CM MUNICÍPIO UF e CM MUNICÍPIO UF PRESIDENTE ANO ATUAL. A identidade independe do nome. Para trocar de pessoa, use Novo presidente: mantém o contato anterior com nome/ano anteriores e limpa dados pessoais do cadastro atual, guardando histórico local. Depois preencha os dados da nova pessoa.

Se uma criação perder a resposta, fica incerta. Aguarde e faça nova prévia: o marcador JP Minato ID é procurado antes de repetir. Se ainda não for encontrado, a operação fica bloqueada para revisão. CSV reimportado manualmente não oferece essa proteção.

2. Verificador com número exclusivo

Protótipo de integração de terceiros WA-JS 4.6.1. Não é a API oficial Meta. Ainda precisa de teste com sessão real; não há promessa de disponibilidade, velocidade ou proteção contra restrições de conta. O código do JP Minato não envia mensagens, arquivos ou convites durante consultas.
  1. Crie um perfil separado no Chrome, instale/recarregue a extensão JP Minato nesse perfil e conecte apenas o número reservado para consultas no WhatsApp Web. O número comercial de envio deve permanecer em outro perfil.
  2. Se usar acesso remoto, autorize o endereço da VPN no ícone da extensão nesse perfil.
  3. No MVP, abra Verificador com número exclusivo, cadastre o telefone desse número e intervalo inicial de 10 segundos ou mais. O intervalo não é garantia contra restrições. Mantenha os adaptadores Evolution/Z-API desativados enquanto usar este protótipo.
  4. Selecione poucos municípios/números conhecidos para o primeiro teste. Inclua um número que você saiba ter WhatsApp e outro que saiba não ter. Use Adicionar números à fila.
  5. Na Agenda Google, confira e salve os contatos correspondentes. Enquanto a gravação não estiver confirmada, a fila mostra Aguardando salvar no Google. Falhas e conflitos da agenda precisam ser resolvidos antes.
  6. No perfil exclusivo, clique Abrir WhatsApp / validador neste perfil. Conecte o número no WhatsApp Web. Na janela da extensão, autorize somente web.whatsapp.com e clique em iniciar. A conta efetivamente conectada é conferida antes de liberar uma consulta.
  7. No MVP, clique Continuar fila. Mantenha a janela do validador e a aba do WhatsApp abertas. A extensão consulta um número de cada vez e devolve o resultado ao servidor pela VPN.
  8. Confira os primeiros resultados e eventuais inconclusivos antes de ampliar. Pausar conserva pendentes; cancelar retira pendentes. Uma consulta já iniciada pode concluir. Resultado inconclusivo exige revisão e nova tentativa explícita.

O Google salva a agenda, mas o WhatsApp entra pelo número de telefone. Não é necessário esperar a agenda Android aparecer no WhatsApp para fazer consulta direta pelo número depois da gravação Google. Falta de foto, formato de celular, nome ausente e erro de conexão não provam ausência de WhatsApp.

O cache automático de existência dura 30 dias; confirmações manuais são preservadas. Números inválidos não são consultados. Nono dígito não é acrescentado automaticamente. Uma resposta a número removido/alterado não modifica o novo telefone. Conta diferente, logout e falha pausam ou impedem novas consultas; não geram resposta negativa inventada.

3. Brasão e rota de captura

Abra o município → Criar PDF/fotos → Buscar brasão no Google / capturar. A pesquisa é brasão MUNICÍPIO UF. Clique num resultado, abra a imagem se necessário e use botão direito → JP Minato → Salvar como brasão deste município. A imagem é salva e aparece na prévia; gere novamente o PDF.

Use os links dessa rota. Abas abertas por fora, clones sem vínculo ou endereço digitado/colado não podem salvar. Reabra pelo cadastro se o vínculo for encerrado. A aba de brasão não pode salvar contatos. Confira sempre nome/UF no título da extensão: escolher uma imagem manualmente não comprova que o brasão pertence ao município.

Fontes públicas além da Wikimedia são aceitas. Downloads internos/privados são bloqueados, inclusive após redirects. Imagens têm limites de tempo/tamanho e resolução. SVG suportado vira PNG transparente; versão anterior e origem ficam guardadas. Para blob/data, fonte bloqueada ou miniatura pequena, baixe a imagem original e use o upload do campo Brasão.

4. Enviar e registrar

Em Enviar PDF, todos os contatos utilizáveis vêm marcados. Desmarque os que não quiser, confira os destinatários e clique Enviar e registrar selecionados. Cada clique abre um destinatário; use o botão do próximo para continuar. E-mails são individuais. Popup bloqueado não gera registro.

Baixe e anexe o PDF manualmente. O registro pelo clique não comprova envio, entrega, leitura ou anexo. A referência do PDF e seu hash ficam associados quando há PDF final disponível. Para corrigir um clique por engano, desmarque o registro no histórico: contadores e filtros são atualizados, com auditoria preservada.
